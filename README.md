# BeTechified Note-Taking API

This is a backend Note-Taking API developed for a group project organised by BeTechified. The API is built using **Node.js** and **Express**.

## Project Overview

The API allows users to create, read, update, and delete notes. It is designed to support collaborative note-taking for teams and individuals.

## Technologies Used

- Node.js
- Express
